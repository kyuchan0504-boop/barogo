‘바로고시스템’은 (주)태성환경연구소 2027학년도 1학기 인턴십 사전 과제로 만든 웹 플랫폼 제안 프로토타입이며, 회사의 공식 웹사이트가 아닙니다.

메뉴 구성과 영상, 홈페이지 링크는 태성환경연구소의 실제 홈페이지·유튜브 채널을 따랐습니다. 사업장 A~H, 측정소 M1~M6, 모든 분석값·센서값·기상값은 가상으로 생성한 시연 데이터입니다. 배출허용기준은 악취방지법 시행규칙 별표 3, 최소감지농도는 Nagata(2003) 값을 사용했습니다.
