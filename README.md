# 바로고시스템 (악취종합병원)

(주)태성환경연구소 2027학년도 1학기 인턴십 사전 과제로 만든 웹 플랫폼 제안 프로토타입입니다.
회사가 내건 ‘악취종합병원’(원인 규명부터 진단 · 설계 · 시공 · 모니터링 · 관제까지)을 웹 서비스 ‘바로고시스템’으로 구현했습니다.
상단 메뉴는 회사 홈페이지와 같은 순서이고, 그 안에 유튜브 영상 232개와 AI 진료 기능을 더했습니다.
회사의 공식 웹사이트가 아닙니다. 메뉴 구성 · 영상 · 홈페이지 링크는 회사의 실제 자료이고, 사업장 · 측정값은 가상 데이터입니다.

상단에는 회사 홈페이지처럼 전체 메뉴 · 통합 검색 · 언어 선택이 있고, PC는 가로 메뉴, 화면 폭 1180px 이하에서는 접이식 메뉴로 바뀌는 반응형입니다.
회사 소식(공지사항 · 보도 · 기술동향)은 2026-11-11에 홈페이지에서 확인한 목록입니다.
모든 계산은 브라우저 안에서 이루어지며 서버나 로그인이 필요 없습니다.

## 검증 결과 요약

- 가상 데이터 타당성 검사 12/12 통과 (배출구>부지경계선 농도, 기준 초과율, 계절성, 관능–기기분석 상관, 풍향–배출원 연계 등)
- 악취지문 판독: 5겹 교차검증 96.5%, 학습 제외 최근 3개월 시료 98%
- 악취 예보: 학습 제외 최근 61일, 시간대 평균 대비 평균오차 47% 감소
- 민원 역추적: 1순위 적중 59% (무작위 13%), 2순위 이내 70%

## 데이터 근거

- 지정악취물질 22종 배출허용기준, 복합악취 기준: 악취방지법 시행규칙 별표 3
- 최소감지농도: Nagata(2003), 삼점비교식 냄새주머니법
- 기상: 울산 연안 평년값 수준 기온, 겨울 북서풍·여름 남동풍, 해륙풍

## 다시 만들기

```bash
cd pipeline
pip install numpy pandas scikit-learn
python gen_data.py    # 가상 데이터 생성 → build/raw.pkl
python validate.py    # 타당성 검사 → build/validation.json
python train.py       # 모델 학습·검증 → build/data.json
python build.py       # 영상 목록(videos.txt) 포함 웹페이지 묶기 → build/index.html
cp build/index.html ../index.html
```
