# 바르고 — 악취종합병원 웹 플랫폼 제안 프로토타입

(주)태성환경연구소 인턴 과제(AI 직무)로 만든 웹 플랫폼 제안 프로토타입입니다.
회사가 내건 ‘악취종합병원’을 **진단 · 해결 · 예측 · 관리** 네 축의 웹 서비스 ‘바르고’로 구현했습니다.
회사의 공식 웹사이트가 아니며, 모든 사업장·측정값은 가상 데이터입니다.

## 화면 구성

| 메뉴 | 하는 일 | 안에서 돌아가는 AI·계산 |
|---|---|---|
| 01 접수 · 문진 | 냄새 설명 문장으로 냄새 유형·의심 물질·필요 검사·의심 사업장 안내 | 키워드 + 글자 2-gram 유사도, 풍향·거리 가중 순위 |
| 02 진단센터 | 지정악취물질 22종 분석값으로 배출원 업종 판독, 기여율·기준 초과 판정 | 다항 로지스틱 회귀(냄새 지문), 복합악취 회귀식 |
| 03 해결센터 | 원인 물질 성질에 맞춘 방지시설 조합·개략 규모 처방 | 물질군 비중 기반 규칙 엔진 |
| 04 예측센터 | 측정소별 24시간 악취 예보, 기상 조건 가정 분석 | 유사 기상 k-최근접 이웃(1년 시간 자료) |
| 05 관리센터 | 측정소 6곳 감시, 경보 이력, 원인 사업장 역추적 | 풍향 정렬 × 거리 × 센서 지문 점수 |
| 전자차트 | 분석 기록을 문장으로 검색, 엑셀·CSV 업로드 후 함께 검색 | 한국어 질의 해석(사업장·물질·기간·조건) |
| 데이터 검증 | 가상 데이터 근거, 타당성 검사 12항목, 모델 성능 | — |

모든 계산은 브라우저 안에서 이루어지며 서버나 로그인이 필요 없습니다.

## 검증 결과 요약

- 가상 데이터 타당성 검사 12/12 통과 (배출구>부지경계선 농도, 기준 초과율, 계절성, 관능–기기분석 상관, 풍향–배출원 연계 등)
- 냄새 지문 판독: 5겹 교차검증 96.5%, 학습 제외 최근 3개월 시료 98%
- 악취 예보: 학습 제외 최근 61일, 시간대 평균 대비 평균오차 47% 감소
- 민원 역추적: 1순위 적중 59% (무작위 13%), 2순위 이내 70%

## 데이터 근거

- 지정악취물질 22종 배출허용기준, 복합악취 기준: 악취방지법 시행규칙 별표 3
- 최소감지농도: Nagata(2003), 삼점비교식 냄새주머니법
- 기상: 울산 연안 평년값 수준 기온, 겨울 북서풍·여름 남동풍, 해륙풍

## 다시 만들기

```bash
cd pipeline
pip install numpy pandas scikit-learn
python gen_data.py    # 가상 데이터 생성 → build/raw.pkl
python validate.py    # 타당성 검사 → build/validation.json
python train.py       # 모델 학습·검증 → build/data.json
python build.py       # 웹페이지 묶기 → build/index.html
cp build/index.html ../index.html
```
